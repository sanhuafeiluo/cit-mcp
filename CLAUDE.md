# cit — Context Information Tracker

This project is managed by cit, a git-style branch system for Claude Code conversations.

## IMPORTANT: When the user says "cit <command>", ALWAYS use the `cit` MCP tool.

Examples:
- "cit squash" → call `cit(command="squash", arg="<auto-generated 1-3 sentence summary>")`. YOU generate the summary from conversation context. Do NOT ask the user to write it.
- "cit branch foo" → call `cit(command="branch", arg="foo")`
- "cit switch foo" → call `cit(command="switch", arg="foo")`
- "cit log" → call `cit(command="log")`
- "cit inbox" → call `cit(command="inbox")`
- "cit close foo" → call `cit(command="close", arg="foo")`

Never interpret "cit" commands as shell/git commands.
